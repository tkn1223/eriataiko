# 対戦表のデザインを作り直す

作った日: 2026-11-21

見本: `2026-11-21-bracket-redesign.png`（yosuke さんが「これで作る」と承認した絵。Codex の案をもとに直したもの）

## なぜ作るか

- 375px のスマホで星取表の右端（4 チーム目）が切れていて、横に動かさないと見えない。
- 決勝トーナメントも横に長く、決勝・優勝の列が画面の外に出ている。
- 試合速報（#78）だけ黒・金の新しい見た目になり、対戦表だけ古い見た目のまま残っている。

## やること

見た目だけを変える。**出す情報と、その決め方（勝ち・負け・順位）は今のまま。**

### 画面の上

- 見出し「対戦表」の右に、札「自分：<チーム名>」を出す。チームに入っていない人（観戦者・チームなし）には出さない。
- タブ「予選リーグ / 決勝トーナメント」は、試合速報のゲームタブと同じ質感（薄い地の上に、選んだ側だけ黒いグラデーション）。高さ 44px 以上。
- 上の帯・下のメニューは変えない（帯は今のとおり大会名だけ。見本の絵の「予選リーグ 1/3 試合」は試合速報の帯を写しただけなので、対戦表には出さない）。

### 予選リーグ：星取表

- カードの見出し「星取表」。右に小さく「<全部の数>対戦中 <終わった数>対戦終了」。
- 見出しの下に 1 行「左のチームから見た結果です。マスを押すと中身が見られます。」
- **375px で 4 チーム × 4 が横に動かさずに収まる**（表の幅を列で等分する）。
- マスの見た目:
  - 勝ち: 金色の地と枠、○ と「2-1」
  - 負け: 灰色の地、● と「1-2」
  - 引き分け: △ と数字
  - 試合中: 薄い緑の地と緑の枠、「試合中」と数字
  - まだ: 灰色の地に「未」
  - 同じチーム同士: 斜めの縞（押せない）
- 自分のチームの行の見出しは金色の地にして、チーム名の下に小さく「自分」。
- 表の下に凡例「○ 勝ち　● 負け　△ 引き分け　未 未実施」「数字は、対戦内の勝ち試合数です。」
- マス（対戦があるもの）は今までどおり押せて、詳細が下から出る。高さ 44px 以上。

### 予選リーグ：順位表

- 見出し「順位表（暫定）」。列は今のまま（順位 / チーム / 勝敗 / ゲーム / 得失点）。
- 自分のチームの行は金色の地。
- 下の注記「順位は 勝敗 → ゲーム → 得失点 の順で決定」は今のまま。

### 決勝トーナメント

- **縦に並べる**（上から 準決勝 → 決勝 → 優勝 → 3位決定戦）。横に動かさずに 375px に収まる。
- 準決勝: 2 つの箱を横に並べる。箱の上に小さく「準決勝①」「準決勝②」と状態（終了 / 試合中 / まだ）。勝った側の行は金色の地、負けた側は薄い字。
- 準決勝と決勝の間を線でつなぐ。
- 決勝: 金色の枠の大きな箱。左右にチーム名（チームの色の線つき）、真ん中に大きく勝ち試合数（まだなら「vs」）。試合中なら緑の「試合中」の札。自分のチームの下に小さく「自分のチーム」。
- 優勝: 決まっていれば今までどおり黒い帯「🏆 優勝：<チーム名>」をいちばん上に。決勝の下の点線の箱には、決まっていれば「優勝　<チーム名>」、まだなら「優勝　まだ決まっていません」。
- 3位決定戦: 準決勝と同じ形の箱 1 つ。
- 空いている枠（「予選1位」など）は今までどおり薄い字。
- 「組み合わせは予選リーグ終了後に確定します」の注記、組み合わせが無い・形が違うときの案内文は今のまま。

### マスを押したとき（詳細）

- 見出し「予選リーグ・対戦詳細」と［閉じる］（44px 以上）。
- 上に結果の箱: 状態（終了した対戦 / 試合中の対戦 / まだの対戦）、左右にチーム名（色の線つき）、真ん中に大きく「2-1」（まだなら「vs」）。終わっていれば下に「○ <チーム名>の勝利」（引き分けは「△ 引き分け」）。自分のチームの下に「自分のチーム」。
- その下に、部ごとのカード: 部の札（色は今のまま `classColorClasses`）、状態（終了 / 試合中 / 未実施）、2 行（チームの色の印＋選手名＋ゲーム数）。負けた側は薄い字。棄権の添え書き（`RetiredNote`）は今のまま出す。
- いちばん下に黒いボタン「星取表に戻る」（押すと閉じる。48px）。
- 背景の暗い部分・Esc で閉じるのは今のまま。

## やらないこと

- **データは変えない。** 表のつくり・入口（`src/app/api/`）・`supabase/`・`src/db/` に手を入れない。
- 勝ち負け・順位の決め方（`src/domain/standings.ts`、`src/usecases/build-bracket-view.ts` の計算）を変えない。
- 列の言葉（勝敗 / ゲーム / 得失点）を変えない。
- 上の帯・下のメニュー・ほかの画面を変えない。
- 決勝トーナメントの箱を押して詳細を出すこと（今も無い）。
- Web フォント・画像・ダークモードを足さない。

## 受け入れ基準

- [ ] 375px と 390px（Playwright で測る）で、予選リーグのタブを開いたとき、ページも星取表も順位表も横にはみ出さない（`scrollWidth <= clientWidth`）。4 チーム目の列の右端が画面の中にある
- [ ] 375px と 390px で、決勝トーナメントのタブを開いたとき、横にはみ出さない。準決勝 2 つ・決勝・優勝・3位決定戦がすべて画面の幅の中にある
- [ ] 星取表の押せるマス・タブ・［閉じる］・「星取表に戻る」は、高さ 44px 以上（実測）
- [ ] チームに入っている人には「自分：<チーム名>」の札が出る。観戦者には出ない
- [ ] 星取表の見出しの右に「<全部>対戦中 <終了>対戦終了」が、渡された対戦の数どおりに出る
- [ ] 星取表のマス: 勝ちは ○、負けは ●、引き分けは △、試合中は「試合中」、まだは「未」。読み上げ用の言葉（勝ち / 負け / 引き分け）は今のまま付いている
- [ ] 自分のチームの行の見出しに「自分」が出る。ほかの行には出ない
- [ ] 順位表の列と数字は今のまま。自分のチームの行だけ地の色が違う
- [ ] 決勝トーナメント: 終わった一戦は勝った側が強調・負けた側が薄い字。試合中の一戦には「試合中」の札。空いている枠は枠の名前を薄い字で出す
- [ ] 優勝が決まっていれば「優勝：<チーム名>」が出る。決まっていなければ「まだ決まっていません」が出る
- [ ] 詳細: 終わった対戦は「○ <勝ったチーム名>の勝利」、引き分けは「△ 引き分け」、まだの対戦は真ん中が「vs」
- [ ] 詳細: 部ごとのカードに、部の札・状態・両チームの選手名・ゲーム数が出る。棄権の添え書きが今までどおり出る
- [ ] 詳細は ［閉じる］・「星取表に戻る」・背景・Esc のどれでも閉じる
- [ ] 色は `src/app/globals.css` の `@theme` と `src/domain/class-labels.ts` だけで決めている（`color-decisions-single-source.test.ts` が緑）
- [ ] `supabase/`・`src/app/api/`・`src/db/`・`src/domain/standings.ts` に差分が無い
- [ ] `npm run check`・`npm test`・`npm run test:e2e` が緑
