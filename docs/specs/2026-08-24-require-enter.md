# 入場していない人を入場画面へ送る

作った日: 2026-08-24

## なぜ作るか

いまは `/courts` を直に開けば、入場せずにそのまま使える。
**最初に必ず入場してもらう**と決めたのに、その入口を通らずに入れてしまう。

**これは守りではない。** 書き込みは `requireOperator()` が別に止めており、
読み取りは元々誰でも見てよいデータ（`docs/security.md`）。
やりたいのは**入口の案内**で、いきなり中身に迷い込まないようにすること。

## やること

`src/app/(app)/layout.tsx` で入場を確かめ、していなければ `/enter` へ送る。

```ts
export default async function AppLayout({ children }: LayoutProps<'/'>) {
  if (!(await getSession())) redirect('/enter');
  return <AppShell>{children}</AppShell>;
}
```

**5 つのタブはすべてこのレイアウトの下**にあるので、1 か所で足りる。
`/enter` はこの外にあるため、**追い返し続ける輪にはならない。**

**観戦者も「入場した人」として通す。** 観戦の入口を押した人が大会の画面を
見られないと、その入口が意味を持たない。

### `middleware.ts` を使わない理由

| | `(app)/layout.tsx` | `middleware.ts` |
| --- | --- | --- |
| 書く量 | 3 行 | 新しいファイル＋対象 URL の指定 |
| Cookie の確認 | 既にある `getSession()` を呼ぶだけ | **署名の検証を書き直す**（実行環境が違う） |
| 対象外の指定 | 不要（`/enter` は外にある） | `/enter` `/api` 画像などを**除外し忘れると事故る** |
| 動くタイミング | ページを描くとき | 画像 1 枚ごとにも動く |

`middleware` が要るのは「守る」場合。今回は守りではないので、軽いほうで足りる。

### 画面テストの入場を 1 か所にまとめる

この変更で、大会の画面を見る画面テストが**全部落ちる**（入場していないため）。
`e2e/helpers/enter.ts` に「観戦者として入場する」を置き、各テストの前で呼ぶ。

**画面を操作せず API を直に叩く。** 入場画面の作りが変わるたびに、
関係のない画面テストまで道連れで壊れるのを避けるため。

## やらないこと

- **元いた場所へ戻すこと**（`/matches` を開こうとした人を、入場後に `/matches` へ）。
  いまは入場すると「大会の画面へ」で `/courts` に入る。必要になったら足す
- 観戦者に得点ボタンを見せない出し分け
- `middleware.ts` の導入

## 受け入れ基準

- [ ] 入場していない状態で `/` `/courts` `/matches` `/bracket` `/me` を開くと `/enter` へ送られる
- [ ] **`/enter` 自体は送り返されない**（輪にならない）
- [ ] 無い URL は今までどおり「ページがありません」が出る
- [ ] **観戦者はそのまま大会の画面を見られる**
- [ ] 名前で入った人もそのまま見られる
- [ ] 退場すると、また入場画面へ送られる
- [ ] 既存の画面テストが全部通る
- [ ] `npm run build` が通る

## 決めたこと

| | 決定 | なぜ |
| --- | --- | --- |
| 置き場所 | **`(app)/layout.tsx`** | 5 タブすべてを覆う唯一の場所。`/enter` はその外なので輪にならない |
| `middleware.ts` | **使わない** | 守りではないので、署名の検証を書き直す価値がない |
| 観戦者 | **通す** | 通さないと観戦の入口が意味を持たない |
| 元の場所へ戻す | **やらない** | まず入口を作る。必要になってから |
| テストの入場 | **API を直に叩く** | 入場画面の作りに他の画面テストを巻き込まない |

## 分かったこと（宿題）

- **すべての画面が「その都度サーバーで描く」形になった**（`npm run build` の表示が
  `○` から `ƒ` に変わる）。Cookie を読むため。本物のデータに繋げばどのみちこうなる
- **CI に `npm run build` が無い。** 今回のような「型は通るがビルドで落ちる」変更を
  取りこぼす。足す価値がある
