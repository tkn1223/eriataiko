# 試合速報：「次のゲームへ進む」ボタン

作った日: 2026-11-23

見本: `2026-11-23-next-game-button.png`（yosuke さんが「これで作る」と承認した絵）

## なぜ作るか

決勝トーナメントは 2 ゲーム先取（上限 3 ゲーム）。今は第1ゲームが終わっても、上の［第1］［第2］［第3］のタブを
自分で押さないと次のゲームに進まない。いちばん目立つボタンが［試合終了］なので、第1ゲームが終わったところで
［試合終了］を押してしまい、1-0 のまま試合が終わる人が出る（11/23 yosuke さん）。

## やること

点を入れる人（担当）のカードだけ。上限ゲーム数が 2 以上の試合だけ（予選のような 1 ゲームの試合は今のまま）。

- **勝負がついていない間**（`matchOutcome(scores, maxGameCount).finished` が false）で、いま出しているゲーム
  （`shownGame`）が上限ゲーム数より前のとき:
  - ± の下に、横いっぱいの黒いボタン「第<shownGame+1>ゲームへ進む ›」（見た目は今の［試合終了］と同じ黒＋金の枠。高さ 52px）
  - 押すと、出すゲームが次のゲームに切り替わる（タブで［第N+1］を押したのと同じ。`chooseGame(shownGame + 1)`）。
    点は送らない（データは何も変わらない）
  - その下に 2 つ並べる: 白いボタン「ここで試合終了」（押したときの動きは今の［試合終了］と同じ。確認画面が出る）と、今の［担当をやめる］。どちらも 44px 以上
- **それ以外**（勝負がついた、または最後のゲームを出している）は今のまま: 黒い［試合終了］と［担当をやめる］の 2 つ
- 上のタブ（第1・第2・第3）は今のまま押せる（前のゲームの点を直すため）

## やらないこと

- 何点でゲームが終わるかの自動判定・自動でタブを切り替えること（点数は部によって違うので、アプリには分からない）
- データ（表・入口・`src/domain/`）を変えること。`matchOutcome` などの決め方も変えない
  （ゲームの途中でも、点が多いほうをそのゲームの勝ちとして数える今の決め方のまま。そのため 1 ゲーム目を取った側が
  2 ゲーム目でもリードしていれば、途中でも［試合終了］が大きく出る。11/23 説明済み）
- 確認画面（`finish-confirm-sheet.tsx`）の中身を変えること
- 担当でない人・観戦者の見た目
- 進行表の訂正の画面

## 受け入れ基準

- [ ] 上限 3 ゲームの試合で、第1ゲームに点が入り（例 21-15）勝負がついていないとき、担当のカードに「第2ゲームへ進む」ボタンがあり、黒い［試合終了］は無く、白い「ここで試合終了」と［担当をやめる］がある
- [ ] 「第2ゲームへ進む」を押すと、出しているゲームが第2ゲームになる（タブの［第2］が選ばれた状態、真ん中が「第2ゲーム」、点は 0-0）。点を送る通信は起きない
- [ ] ゲームが 1-1 のとき第2ゲームを出していれば「第3ゲームへ進む」が出る
- [ ] 第3ゲーム（最後のゲーム）を出しているときは「…へ進む」は出ず、黒い［試合終了］が出る
- [ ] どちらかが 2 ゲーム取った（`matchOutcome` が終わり）ときは「…へ進む」は出ず、黒い［試合終了］が出る
- [ ] 「ここで試合終了」を押すと、今の［試合終了］と同じ確認画面が出る
- [ ] 上限 1 ゲームの試合（予選）は、今と同じ（黒い［試合終了］と［担当をやめる］だけ）
- [ ] 担当でない人・観戦者のカードには「…へ進む」も「ここで試合終了」も出ない
- [ ] 375px と 390px で、ボタンがカードからはみ出さず、どれも高さ 44px 以上（Playwright で測る）
- [ ] 色は `@theme` と `class-labels.ts` だけ（`color-decisions-single-source.test.ts` が緑）
- [ ] `supabase/`・`src/app/api/`・`src/db/`・`src/domain/`・`src/usecases/` に差分が無い
- [ ] 型・lint・整形・`npm test`・`npm run test:e2e` が緑

## 決めたこと

- 案A（［試合終了］を押したら注意を出す）と案B（次へのボタンを出す）を並べ、yosuke さんが B を選んだ（11/23）。
- 2026-09-04 の決定（「ゲーム終了」ボタンを持たず、どの枠も押せる。表に「ゲームが終わった印」を持たない）は守る。
  今回のボタンは**出すゲームを切り替えるだけ**で、何も保存しない。
- 1-0 のまま終わらせる道は残す（「ここで試合終了」）。決勝で時間切れなどがありうるため（2026-09-04 の仕様）。
- 第1ゲームを取った側が第2ゲームでリードした瞬間に、黒い［試合終了］が大きく戻る（今の数え方のため）。
  そこで押しても確認画面に各ゲームの点が並ぶので気づける、として**このまま出す**（11/23 yosuke さん。当日の様子を見て考え直す）。
- **2026-11-26 見直し**: 上の「このまま出す」をやめた（yosuke さん。実際に第2ゲーム 19-16 で黒い［試合終了］が大きく戻るのを見て）。
  「…ゲームへ進む」は**点数に関係なく、最後のゲームより前なら出し続ける**。2-0 で本当に終わったときも、
  終わらせるのは下の白い「ここで試合終了」（確認画面に各ゲームの点が並ぶ）。上の「勝負がついたら出さない」の受け入れ基準はこれで置き換える。
