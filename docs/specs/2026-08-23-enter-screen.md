# 入場画面を参考アプリの見た目にそろえる

作った日: 2026-08-23

## なぜ作るか

入場画面だけ、ほかの画面と作りが違う。進行表・対戦表・マイページ・結果LIVE は
運用中のアプリ（badminton-app）の見た目に寄せてあるのに、入場画面は
**Konsta のラジオボタンの一覧のまま**で、1 画面だけ浮いている。

参考アプリには**同じ役割の画面がある**（実際に開いて確認した）。

| | 参考アプリ |
| --- | --- |
| 1 画面目 | 「あなたのチームを選んでください」— チームのカードが縦に並ぶ |
| 2 画面目 | 「あなたの名前をタップ」— 部ごとに、名前のボタンが **2 列**で並ぶ |

**参考アプリに合言葉は無い。** そこだけこちらの都合で足す。

## やること

### 1. 2 段階にする（参考アプリと同じ）

```
チームを選ぶ  →  名前をタップ  →  合言葉のシートが下から出る  →  入場
```

**チームがまだ登録されていないときは、1 画面目を飛ばして名前の一覧を出す。**
いまの本番がその状態（選手 6 名・大会 1 つ・参加 6 件だけで、チームも部も無い）。
飛ばさないと、空のチーム一覧で行き止まりになる。

チームに属さない人（試合に出ない入力係など）がいるときは、
チーム一覧の最後に「チームなし」のカードを出す。

### 2. 見た目を参考アプリに合わせる

実際の画面から測った値。

| | 値 |
| --- | --- |
| 背景 | `#f2f1ec` |
| 枠線 | `1px solid #e4e2da` |
| 薄い文字 | `#8b867c` |
| 上の飾り | `BADMINTON TOURNAMENT` / 11px / w800 / 字間 3.08px |
| 大会名 | 22.4px / w900 |
| 問いかけ | 17px / w900 |
| 部の見出し | 12px / w800 / 薄い文字 |
| チームのカード | 白・角丸 16px・内側 18px・高さ 72px。左にチーム色の縦棒（幅 10・高さ 34・角丸 6） |
| 名前のボタン | 白・角丸 12px・内側 14px/8px・高さ 51px・15px / w800。**2 列・すき間 8px** |
| 「← 戻る」 | 白・角丸 999px・8px/16px・13px / w800 |

背景色は**この画面の中だけ**に敷く。`body` に敷くと Konsta の配色と喧嘩して、
ほかの画面まで色が変わる。

### 3. 大会名を本物にする

参考アプリはここに大会名を出す。こちらは固定文字（`TOURNAMENT_NAME`）だった。
入場画面はもともと「いまの大会」を読んでいるので、**その名前をそのまま出す**。
ほかの画面のヘッダーは今回は触らない。

### 4. 合言葉は名前をタップしてから聞く

名前を押すと、下からシートがせり上がって合言葉の欄が出る。
**合言葉が設定されていないときはシートを出さず、そのまま入場する。**

合言葉の欄の指定は PR #39 で決めたものをそのまま持ち越す。
**伏せ字にしない・`one-time-code` を使わない。** 理由は `e2e/enter.spec.ts` に書いてある。

## やらないこと

- **観戦者用の入口。** 参考アプリの下にある「観戦の方はこちら（名前の登録なし）」。
  合言葉を持たないセッションの形をサーバー側に作る必要があり、別の PR にする
- ほかの画面のヘッダー（`TOURNAMENT_NAME` の置き換え）
- `requireOperator()` に `can_input` の確認を足すこと（別の PR）
- チーム・部の本番登録（スプレッドシートからの取り込み）

## 受け入れ基準

- [ ] チームが登録されているとき、1 画面目にチームが並ぶ
- [ ] チームのカードに人数が出る
- [ ] チームを選ぶと、そのチームの人だけが名前のボタンで並ぶ
- [ ] 名前は部ごとにまとまり、部の見出しが出る
- [ ] 「← 戻る」でチーム選びに戻れる
- [ ] **チームが 1 つも無いときは、いきなり名前の一覧が出る**（行き止まりにならない）
- [ ] チームに属さない人がいるとき、「チームなし」から選べる
- [ ] 名前を押すと合言葉のシートが出る
- [ ] 合言葉が設定されていないときはシートが出ず、そのまま入場できる
- [ ] 合言葉の欄が伏せ字になっていない／`one-time-code` になっていない（PR #39 の 2 件を維持）
- [ ] 合言葉が違うと画面にその旨が出る
- [ ] 入場後は「入場中」と名前・番号が出て、退場できる
- [ ] 同名の 2 人を番号で見分けられる
- [ ] 390px 幅で横にはみ出さない（Playwright で実測）

## 決めたこと

| | 決定 | なぜ |
| --- | --- | --- |
| 段階 | **2 段階**（参考アプリと同じ） | 当日は 100 人。1 画面に並べると 50 行ぶんスクロールすることになる |
| チームが無いとき | **1 画面目を飛ばす** | いまの本番がその状態。飛ばさないと空の画面で止まる |
| 合言葉 | **名前をタップしてから** | 参考アプリには無い手順なので、参考アプリの流れを壊さない位置に置いた |
| 背景色 | **この画面の中だけ** | `body` に敷くとほかの画面の配色まで動く |
| 観戦者の入口 | **今回は作らない** | サーバー側にセッションの形を足す必要があり、別の話になる |
