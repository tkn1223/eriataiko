# myページをデザイン案どおりに作り直す

作った日: 2026-11-22

デザイン案: `docs/specs/2026-11-22-me-redesign.png`（デザインの AI が作り、yosuke さんが承認。A〜E の見本と「変えた点と理由」）

## なぜ作るか

当日、選手が myページを開いて知りたいのは「次はどのコートか」。今はそれが右端の小さな灰色の字で、
押すと即退場する「別の人として入り直す」が一番上にあり、勝ち（○）・負け（●）・未実施（待）の印も見分けにくい。
試合速報（#78）と見た目も揃っていない。

## やること
**選手の画面（上から）**
1. 見出し：チーム色の丸＋名前、チーム名＋部の色付き札（チーム無しは「チームなし」、部なしは札なし）
2. **次の試合（金枠カード）**：未実施でいちばん近い 1 試合。部の札、「コート◯」を大きく＋「◯試合目」。コート未定は「コート未定／コートが決まるとここに大きく出ます」、順番未定は「順番未定」。下に 回戦／ペア（シングルスは出さない）／相手＋相手チーム名
3. **そのあとの試合**：残りの未実施を白いカードで。「予定」の印、回戦＋部の札、vs 相手、相手チーム名＋「◯◯ とペア」、右にコート・◯試合目
4. **終わった試合**：見出しの右に「◯勝◯敗」。1 枚のカードにまとめ、勝＝金の塗り／負＝白抜き枠。各ゲームの点、右にゲーム数。棄権は「（◯◯ 棄権）」を濃い金で
5. 全試合が終わったら、2 の位置に金枠で「全試合が終わりました ◯勝◯敗」
6. 一番下に「‹ 名前を選ぶ画面に戻る」（今の「別の人として入り直す」の改名。確認なし・動きは同じ）
7. ヘッダーの小見出し：「myページ · あと◯試合」／「myページ · 全試合終了」／観戦者は「myページ · 名前を選ぶ」（既存の `NavbarSubtitle` を使う）
- カードは試合速報と同じ作り（角丸 18〜20px・薄い影・部は色付きの丸い札）。色は既存の色だけ

**並び順・数え方（デザイン案の見本に合わせて決めた）**
- 未実施は「◯試合目」の若い順 → 同じならコート番号の若い順。順番未定・コート未定は後ろ
- 「あと◯試合」は終わっていない試合（試合中＋未実施）の数
- 試合中の試合だけが残っていて未実施が無いときは、金枠を出さない（小見出しは「あと1試合」）
- 試合が 1 つも無い人（入力係など）は「まだ試合が登録されていません」と出す

**データ（読むだけ。表は変えない）**
- 相手チーム名を足す：`src/db/me.ts` の `findMatchPlayersByMatchIds` で participants を読むときに `teams(name)` も一緒に読む（読む回数は増えない）。ペアの 2 人のチームが違えば「・」でつなぐ
- 名前選びのデータ（参加者・チーム・部・合言葉の要否）を読む処理を `src/app/enter/page.tsx` から `src/db/` の関数に移し、入場画面と myページで共用する

## やらないこと
- 表のつくり・書き込みの入口の変更
- 試合中の点を myページに出すこと、自動での読み直し
- 名前選びの検索欄（見本 D の検索欄は仮組み。既存の名前選びの見た目のまま）
- 「名前を選ぶ画面に戻る」に確認を挟むこと
- 通算の「ゲーム数」「得失点」の表示（デザイン案で削除。計算の部品 `src/domain/player-record.ts` は残す）
- 入場画面（`/enter`）の見た目の変更

## 決めたこと

- 観戦者が myページを開いたら、**入場の名前選び（既存の `EntryGate`）を myページの中に出す**。選んだらそのまま自分の myページになる。下のメニューは残る
- **試合中の試合は myページに出さない**（「次の試合」はその次の未実施の試合）
- **過去の決定（`docs/specs/2026-09-05-me-real-data.md`）から変えた点。** 進行中を一覧の先頭に出す → 出さない。
  観戦者には「観戦モード」の案内 → 名前選びそのもの（「名前を選ぶ仕組みは入場に既にあるので二重に作らない」は守り、部品を共用する）。
  成績カードの「ゲーム」「得失点」→ 出さない（知りたいのは勝ち負けの数。細かい点は一覧で分かる）
- **試合中を出さない理由**: 本人は試合中に画面を見ない（点は審判が示す）。試合の合間に要るのは次の行き先
- **「名前を選ぶ画面に戻る」に確認を挟まない理由**: 押し間違えても名前を選び直すだけ。位置（一番下）で誤タップを防ぐ
- **並び順を「◯試合目」優先にした理由**: コートは並行して進むので、試合目の数が時間の近さに近い（デザイン案 A・B の並び）
- **終わった試合は古い順**（試合目 → コート番号の若い順。11/22 yosuke）。デザイン案の見本は新しい順だったが、1回戦から順に読めるほうを選んだ
- 作りながら決めたこと: 試合が 0 件の人の小見出しは「myページ」だけ／「そのあとの試合」は未実施が 2 件以上のときだけ出す

## 残した宿題

- 名前選びの検索欄（デザイン案 D にあるが仮組み。人数が増えたら考える）
- 未実施の試合の「近さ」は試合目の数で近似している。コートごとに進み方が違うと前後しうる
