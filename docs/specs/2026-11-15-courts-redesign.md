# 結果LIVE のデザインを作り直す（得点板の形・出すものを絞る）

作った日: 2026-11-15

## なぜ作るか

結果LIVE は、部品を 1 つずつ足してきたので情報が多く、IT が得意でない人には「どこを見て、どこを押せばいいか」が分かりにくい。
点数が選手名から離れていてどちらの点か一目で分からない、上の見出しで縦の場所を取りカードが下に押される、
次の試合・1つ前・担当の名前などが全部の人に並ぶ、といったことが重なっている。

**コンセプトは「IT が得意でない人でも迷わず使える」。** 開く人の目的ごとに、要るものだけを出す。

ふるやさんから「データをいじらずにデザインを変えるのはやってよい」と言われている（2026-11 時点）。
yosuke さんの担当は結果LIVE と対戦表。**この PR は結果LIVE だけ**（1 画面 = PR 1 本）。

デモ画像: `docs/specs/2026-11-15-courts-redesign.png`（左から ① 点を入れる人 ② 選手 ③ 観戦者、375px）

## 開く人と目的

| 開く人 | 目的 |
| --- | --- |
| 点を入れる人（その試合の担当） | 自分のコートの点を入れる・試合を終える・まちがいを直す |
| 選手（担当していない） | 自分の試合がどうなっているか、いま何点かを知る |
| 観戦者 | いま何点かを見るだけ |

```
┌ コート2  [2部] ──────────── (試合中) ┐
│               第2ゲーム               │
│   (第1ゲーム 21-15 東日本の勝ち)       │  ← 終わったゲームがあるときだけ
│ ┌─── 東日本 ───┐ ┌── 愛知中央 ──┐     │  ← 上の太い線と薄い塗りがチームの色
│ │ リサ          │ │ ガット        │     │
│ │ ぷりケツまな  │ │ 柑橘ルパン    │     │
│ │      14       │ │      11       │     │
│ └───────────────┘ └───────────────┘     │
│ （ここに担当の欄。下の表）              │
└──────────────────────────────────────┘
```

- 1 行目: 「コートN」（大きく太く）、部の札（いまの部の色）、右端に状態の札
  - 試合中＝緑、呼出待ち＝黄、直し中・終了も同じ形の札で出す（色は実装で決めてよい。ほかと見分けがつくこと）
- 2 行目: 「第Nゲーム」（いま入れているゲーム）を真ん中に小さく
- 終わったゲームがあれば、その下に小さな札で「第1ゲーム 21-15 東日本の勝ち」（ゲームごとに 1 つ。予選は 1 ゲームなので出ない）
- 左右 2 枚の枠。上から **チーム名（チームの色の文字）・選手名（1 人 1 行）・大きな点数**
  - 枠は上に太い線、全体を薄く、どちらも**チームの色**（`src/domain/class-labels.ts` の 1 か所から。ほかで色を決めない）
  - チームが決まっていない側（決勝の「予選1位」など）は灰色の枠に空枠ラベルを出す
  - 棄権の印・勝敗の出し方は今と同じ意味のまま、新しい見た目に合わせる
- **自分の試合**は「あなたの試合」の札をやめ、カードの枠を太い金色で囲む
- 呼出待ちのコートは、次の試合をこの形で出す（0 対 0、札は「呼出待ち」）。観戦者にも同じ形で出す（ボタンは無し）

### 次の試合・1つ前の試合

- 進行中のカードの下に出していた「次」の行は**出さない**（進行表で見る）
- 1つ前の試合（［訂正］つき）は、**次の人にだけ**出す
  - その 1つ前の試合に出た選手（`PreviousMatch.isMine`）
  - いまそのコートの進行中の試合の担当（自分が担当のとき）
- 1つ前の行は 1 行で「1つ前　■愛知北 2-1 ■愛知西　［訂正］」。1 ゲーム制なら点数、複数ゲーム制なら取ったゲーム数。棄権なら今と同じく分かるようにする
- 観戦者・上に当てはまらない選手には、1つ前の行を出さない
- 試合が全部終わったコート（進行中も次も無い）は、1つ前を出せる人にはカードを残して 1つ前の行を出す。それ以外の人には「このコートの試合は終わりました」と短く出す（真っ白にしない）

## 決めたこと

2026-11-15 に yosuke さんとデモ画像を見ながら決めた。

1. 方向は**得点板の形**（yosuke さんが見本の画像を出した）。左右にチームの色の枠、上からチーム名・選手名・大きな点数
2. ＋ − は**各チームの枠の真下**。どちらのチームの点か迷わないため。**＋と−は同じ大きさ**（yosuke さん）。色は分ける（＋は黒、−は白）。形が同じでも色で見分けられるように
3. ほかの人が担当のときは、**灰色の帯に名前＋小さめの［入力を引き継ぐ］**（大きなボタンの案より、うっかり押しにくい）
4. 終わったゲームの点は、**上に小さな札**（チームの中に入れる案・下に表の案より、場所を取らず一目で分かる）
5. 何を出すかは「開く人の目的」で絞る（yosuke さん「ごちゃごちゃしてきた。取捨が必要」）
   - 次の試合は出さない（進行表にある）
   - 「あなたの試合」の札はやめて、枠の色で示す（文字を 1 つ減らす）
   - 上の見出しは 1 行に縮める
   - 観戦者には、誰が入力しているかも出さない（yosuke さん）
6. 1つ前の［訂正］を出すのは、**その試合に出た選手＋いまそのコートの担当**。
   「いまの担当だけ」にすると、コートの最後の試合が終わったときに誰も直せなくなるため。
   #76（得点入力の担当）の ⑩「直すは誰でも押せて、押した人が担当になる」のうち、**押せる人（入口）は変えない。画面に出す人だけを絞る**

7. 下のメニューの「結果LIVE」を **「試合速報」** にする（yosuke さん）。
   理由: 「結果LIVE」は IT が得意でない人に伝わりにくい。候補 20 個から yosuke さんが選んだ。
   速報の勢いがあり、何の速報か分かり、4 文字でメニューに収まる

8. ボタン名を「何の担当か・何をするか」が分かる言い方にそろえる（yosuke さん）。
   「担当をやめる」は、隣の［試合終了］と『終了』がかぶって押し間違えるのを避けるため、yosuke さんの案「入力担当を終了」から変えた。
   「第1G：21-15」は短さを優先して yosuke さんが選んだ

9. 色合いは yosuke さんが出した見本画像（黒・金・白）に合わせる。上の帯・下のメニューも含む（yosuke さん）。背景は最初クリーム色の案だったが、白に決めた

## 実装で決めたこと（仕様に無く、実装の側で決めた。要確認）

- **ゲームを進める・戻す矢印**: カードは「いま入れている 1 ゲーム」だけを出すので、次のゲームの点を入れる手段が要る。
  点を入れる人の、複数ゲーム制のカードにだけ「第Nゲーム」の両側に矢印（‹ ›、44px 以上）を足した。観戦者・1 ゲーム制には出ない。
  矢印を押さなければ、点が入っている一番後ろのゲームを出す
