# domain — 大会そのもののルール

**ここには計算だけを置きます。** DB も画面も HTTP も触りません。

置くもの:

- 試合のルール（21 点で勝ち、20-20 のデュース、何ゲーム先取か）
- 順位の計算（勝敗 → ゲーム → 得失点の順で並べる）
- ペアの組み方（同じ部の中から、カードごとに入れ替える）
- 勝ち上がり表の組み立て（予選リーグ → 準決勝 → 決勝・3位決定戦）
- `repositories.ts` … 「DB はこう使う」という約束だけ（実装は `src/db/` に書く）

置かないもの:

- `supabase` を触るコード → `src/db/`
- 画面の部品 → `src/ui/`
- 「得点を 1 点入れる」のような操作の手順 → `src/usecases/`

## なぜ分けるか

ここは**一番バグると困る場所**です。順位を間違えると大会が荒れます。

そして DB も画面も要らないので、テストがミリ秒で書けます。
新しいルールを足すときは、まず `*.test.ts` に例を書いて赤にしてから実装してください。

```
src/domain/standings.test.ts   ← 先にこれ
src/domain/standings.ts
```
