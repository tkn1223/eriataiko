# マイページ（/me）— 表示だけ

作った日: 2026-08-16

## なぜ作るか

選手が「自分は何勝何敗か」「次はどのコートか」を知る場所が無い。
いまの `/me` は「準備中！！」と出るだけ。

ただしデータの置き場所（表）がまだ無い（`supabase/migrations/` にあるのは
`operators` と `write_logs` だけ）。そこで先に見た目だけ作り、中身は見本のダミーで埋める。

## やること

`/me` に、選手として登録済みの人の画面を出す。上から順に:

1. 右寄せの「名前を変更」— 押すと「準備中」と表示（画面は切り替わらない）
2. 見出し部 — 64px の丸アバター（チーム色の背景・名前の頭 1 文字）＋ 名前 ＋「チーム名 ・ 2部」
3. 成績カード — 「3勝1敗」（大きく）＋ 右に小さく「ゲーム 7-3」「得失点 +21」
4. 「今大会の試合」の見出し
5. 試合の一覧。1 件ずつ:
   - 左の丸バッジ … 勝ち `○` / 負け `●` / 進行中 `LIVE` / 未実施 `待`
   - 中央 … 上段「予選 1回戦 ・ 山田 とペア ・ 2部」、下段「vs 佐藤・鈴木」
   - 右 … 上にゲーム数「2-0」、下に各ゲーム「21-15 / 21-18」。未実施は「コート3・2試合目」

見た目は運用中のアプリ（badminton-app）の myページに合わせる。

## やらないこと

- DB からの読み取り（`src/db/` を一切触らない。ダミーの定数を使う）
- 観戦モードの画面
- 名前の登録・変更の中身（押すと「準備中」で終わり）
- 「新しい大会を作る（現在のデータを消去）」ボタン
- 成績の計算（勝敗・ゲーム・得失点はダミーに数値として持たせる）

## 受け入れ基準

- [ ] `/me` を開くと、選手の名前・チーム名・部が出る
- [ ] 成績カードに「◯勝◯敗」「ゲーム ◯-◯」「得失点 ±◯」が出る
- [ ] 「今大会の試合」の下に試合が並ぶ
- [ ] 勝ち `○`・負け `●`・進行中 `LIVE`・未実施 `待` が、試合の状態どおりに出し分けられる
- [ ] 未実施の試合は、スコアの代わりに「コート◯・◯試合目」が出る
- [ ] ペアの相手がいる試合は「◯◯ とペア」、いない試合は「シングルス」と出る
- [ ] 「名前を変更」を押すと「準備中」と出て、画面は切り替わらない
- [ ] 観戦モードの表示と「新しい大会を作る」は出ない
- [ ] 390px 幅で横にはみ出さない（Playwright で実測）
- [ ] 一番下の試合が、下のメニューに隠れない（Playwright で実測）
- [ ] `/me` の画面のコードが `src/db/` を import していない

## 決めたこと

- **ボタンは見た目だけ。**「名前を変更」は押すと「準備中」と出るだけにした。
  データの保存先がまだ無いので、動かすと作り直しになる。
- **「新しい大会を作る（現在のデータを消去）」は置かない。**
  参考アプリでは myページにあるが、誰でも見える画面に全消しボタンがあると
  大会当日の誤タップで全滅する。運営専用の画面ができたらそちらに置く。
- **観戦モードは作らない。** 今回は選手の画面だけ。
- **表示専用にする。** `my-page.tsx` は props を受け取って描くだけにし、
  データの出どころを知らせない。本物のデータが来たら `page.tsx` の渡す中身を
  差し替えるだけで済む。
- **Tailwind で個別に作る。** Konsta に無い形なので（`AGENTS.md` の方針どおり）。

## 残した宿題

- 本物のデータをつなぐ（`players` / `matches` などの表がまだ無い）
- 観戦モードの画面
- 名前の登録・変更
- 運営専用の画面（大会のリセットなど危険な操作はそちらへ）
