# CSV で大会を取り込む

大会の中身（大会・会場・部・チーム・選手・組み合わせ）を、3 枚の CSV からまとめて入れます。
**たかひろさんが PC でコマンドを打って取り込みます。** 画面はありません。

見本は `docs/import-sample/` にあります（名前は架空）。まずこれをコピーして書き換えるのが早いです。

---

## 使い方（4 ステップ）

1. 1 つのフォルダに `大会.csv` `選手.csv` `試合.csv` の 3 枚を入れる
2. 取り込む

   ```bash
   node --env-file=.env.local scripts/import-competition.mjs <フォルダ>
   ```

   - 最初に「つなぐ先」が出ます。**本番かどうか、ここで必ず見てください。**
     `http://127.0.0.1:54321` なら手元、`https://〜.supabase.co` なら本番です
   - CSV に問題があれば、**全部まとめて**「何ファイルの何行目が、どうおかしいか」が出ます。何も書き込まれません。直してもう一度実行します
   - 問題が無ければ件数が出て、`y` を押して Enter するまで書き込みません（`--yes` を付けると省略できます）
   - 終わると、「空枠として入れたチーム欄」の一覧が出ます。決勝の「予選1位」などが意図どおりか確かめます

3. 「いまの大会」を切り替える（取り込んだだけでは切り替わりません）

   ```bash
   node --env-file=.env.local scripts/set-current-competition.mjs 2026-11-23
   ```

   日付はその大会の開催日です。その日付の大会がちょうど 1 つあるときだけ動きます。

4. 画面で結果 LIVE・対戦表・マイページを見る

手元で練習するときは、`.env.local` のかわりに `.env.test`（手元のデータベース）を使います。

### 直したいとき

CSV を直して**同じコマンドをもう一度**実行します。同じ日付の大会は（同じ日に大会は 1 つだけと考えます）、
中身を消して入れ直します（「いまの大会」の印は残ります）。

**日付は変えないでください。** 日付で同じ大会かどうかを見分けています。
大会名の誤字は直して構いません（入れ直すと名前も直ります）。日付を変えると別の大会がもう 1 つ作られます。
同じ日付の大会が 2 つあると、取り込みも「いまの大会」の切り替えも止まります。古いほうを消すコマンドはありません。

**点が 1 つでも入っている、または始まった試合がある大会は入れ直せません。**
何も書き換えずに止まります（選手の名前の誤字だけでも同じです）。
当日になったら、組み合わせの直しは別の方法で相談してください。

#### 点が入ったあと、選手の名前の誤字だけどうしても直したいとき

直すコマンドはありません。Supabase の管理画面で 1 人ずつ直します。

1. Supabase の管理画面を開き、対象のプロジェクトを選ぶ
2. 左の「Table Editor」から `players` を開く
3. `player_number`（選手番号）で該当する人の行を探す
4. その行の `name` の欄だけを直して保存する

**触るのは `name` の欄だけです。** 他の欄・他の表は触らないでください。
本番のデータなので、直す前に番号と名前をもう一度見比べて、慎重にやってください。

入れ直すと、試合は作り直しになります。開いたままの画面は、読み込み直すと新しい中身になります。
入れ直しの数秒のあいだ、画面に試合が出ないことがあります。

途中で失敗したときは、もう一度実行してください。丸ごと入れ直すので、やり直しても安全です。

## 大会.csv

「種類」ごとに 1 行ずつ書きます。

```
種類,名前,値
大会,第5回 愛知エリア対抗バド大会,2026-11-23
会場,◯◯体育館,9
面数,,9
チーム,東日本,1
部,1部,
段,予選リーグ,リーグ
ゲーム数,予選リーグ/1部,1
```

| 種類 | 名前 | 値 | 数 |
| --- | --- | --- | --- |
| 大会 | 大会の名前 | 開催日（`2026-11-23` の形） | ちょうど 1 行 |
| 会場 | 会場の名前 | その会場で使える面数 | ちょうど 1 行 |
| 面数 | （空でよい） | 今年押さえた面数。コート番号の上限の確認に使う | ちょうど 1 行 |
| チーム | チームの名前 | チーム番号（色。1〜4） | 1 行以上 |
| 部 | 部の名前 | （空） | 1 行以上。書いた順が並び順 |
| 段 | 段の名前 | `リーグ` か `トーナメント` | 1 行以上。書いた順が並び順 |
| ゲーム数 | `段の名前/部の名前` | 最大何ゲームやるか | 試合に使う「段 × 部」の全部 |

- 会場は名前で探します。同じ名前があれば使い回し、無ければ作ります（面数は書いた値に更新）
- 試合のゲーム数は試合.csv には書きません。ここの「ゲーム数」が各試合にコピーされます

## 選手.csv

```
選手番号,名前,チーム,部
5001,ハルキ,あおぞら,1部
5025,スタッフ ミナト,,
```

- **選手番号は年をまたいでずっと同じ人に同じ番号**です。番号が既にある人は作り直さず、名前が違えば直します
- チームと部は空でも構いません（試合に出ない係の人）
- チームと部は、大会.csv に書いた名前にします

## 試合.csv

1 行が 1 試合です。

```
段,対戦,対戦の順番,チームA,チームB,部,対戦の中の順番,コート,コートの中の順番,A1,A2,B1,B2
予選リーグ,予選 第1試合,1,あおぞら,もみじ,1部,1,1,1,5001,5002,5007,5008
```

| 列 | 意味 |
| --- | --- |
| 段 | 大会.csv の段の名前 |
| 対戦 | 対戦の名前（「準決勝1」など）。**同じ「段＋対戦」の行が、1 つの対戦（チーム対チーム）にまとまります** |
| 対戦の順番 | 段の中での対戦の並び順（1 以上の整数） |
| チームA / チームB | 大会.csv のチーム名。トーナメントの段なら、チーム名でない値（「予選1位」）も書けます＝空枠 |
| 部 | 大会.csv の部の名前 |
| 対戦の中の順番 | その対戦の中で何番目の試合か（1 以上。対戦の中で重ならない） |
| コート | コート番号（数字。1〜面数） |
| コートの中の順番 | そのコートで何番目か（1 以上。**同じコートで重ならない**） |
| A1 A2 B1 B2 | 出場する選手の番号。トーナメントで未定なら 4 つとも空 |

決まりごと:

- **同じ対戦の行は、チームA・チームB・対戦の順番を全部同じ**にします
- リーグの段では、チーム名は大会.csv にあるものだけ。出場者も必ず書きます
- **リーグでは、同じ 2 チームの対戦を 2 つ以上作れません**（星取表が崩れるため）
- **トーナメントの段は、対戦をちょうど 4 つ**にして、**対戦の順番を重ならない番号**にします。
  画面は並び順で「1・2 番目が準決勝、3 番目が決勝、4 番目が 3位決定戦」と決めます
  （準決勝1 → 準決勝2 → 決勝 → 3位決定戦の順）
- ダブルスなので、片側は 2 人そろえるか、2 人とも空にします
- 出場者のチームは、その側のチームと同じ。出場者の部は、その試合の部と同じ
- 決勝の空枠は、予選の結果から自動では埋まりません。決まったら人が直します

## 運営のスプレッドシートから写すコツ

運営の表は印刷用の見た目なので、そのままは読めません。
**スプレッドシートに「取り込み用」タブを作り、数式で写します。** 運営の表を直せば取り込み用も追いつきます。

- 取り込み用タブは、1 行目に上の列名、2 行目から 1 試合ずつ
- 運営の表のコートが A〜I のときは、`=MATCH(元のセル, {"A","B","C","D","E","F","G","H","I"}, 0)` で 1〜9 にします
  （アプリのコート表示は 1〜9。A〜I にするかは、まだ決めていません）
- 選手の名前から番号を引くには `=VLOOKUP(名前, 選手一覧!A:B, 2, FALSE)` のように、名前と番号の対応表を別タブに作ります
- 数式の結果は「値」になっていないと CSV に出ないことがあります。タブを CSV として保存（ファイル → ダウンロード → CSV）すれば、見えている値が出ます
- ダウンロードした 3 枚は、名前を `大会.csv` `選手.csv` `試合.csv` に直してフォルダに入れます
- Excel で開いて保存し直すと、文字化けや番号の先頭の 0 落ちが起きることがあります。Google スプレッドシートからのダウンロードを使ってください

## よく出るエラーと直し方

エラーは「ファイル名 + 行番号: 理由」で出ます。行番号は 1 行目が見出しです。

| 出るもの | 直し方 |
| --- | --- |
| `必須の列「値」がありません` | 1 行目の列名が違う、または列が足りません。見本と同じ列名にします |
| `知らない種類「…」です` | 大会.csv の「種類」を、大会・会場・面数・チーム・部・段・ゲーム数のどれかにします |
| `日付は YYYY-MM-DD の形…` | `2026/11/23` ではなく `2026-11-23` にします |
| `チーム番号は 1〜4…` / `重なっています` | チーム番号は 1〜4 を 1 回ずつ |
| `段「…」は 大会.csv にありません` | 試合.csv の段の名前を大会.csv の「段」と同じ綴りにします（空白の違いに注意） |
| `チームA のチーム「…」は 大会.csv にありません` | チーム名の綴りを直します。空枠にできるのはトーナメントの段だけです |
| `大会.csv の「ゲーム数」に「予選リーグ/1部」がありません` | 試合に使う「段/部」の組を、すべてゲーム数に書きます |
| `選手番号 … が 選手.csv にありません` | 選手.csv に行を足すか、番号の打ち間違いを直します |
| `選手 … はチーム「…」の人です` | その側のチームに所属する人の番号にします（A と B の入れ違いも多いです） |
| `選手 … は部「…」の人です` | その試合の部に出る人にします |
| `コートは 1〜9 の整数にしてください` | 面数を超えています。コートを数字にしたか、面数の行が合っているか確かめます |
| `コート … の … 番目が … 行目と重なっています` | 同じコートで同じ順番の試合が 2 つあります |
| `リーグで「…」と「…」の対戦が 2 つ以上あります` | 同じ 2 チームの対戦を 1 つにまとめます |
| `トーナメントの段「…」の対戦が … つです` | 決勝トーナメントは 4 つ（準決勝2・決勝・3位決定戦） |
| `…と同じ対戦なのに、チームBが違います` | 同じ「段＋対戦」の行で、チームA/B と対戦の順番を揃えます |
| `面数（…）が会場「…」の面数（…）より多くなっています` | 大会.csv の「面数」を、会場の面数以下にします（書き間違いが多いです） |
| `この大会にはもう点が入っています` | 点が入った大会は入れ直せません（仕様です） |
