# セキュリティの方針

趣味で作って仲間内で使うアプリです。URL は関係者に配りますが、**インターネットには公開されています**。
そのため「どこまで守るか」をはっきり決めて、そこに力を入れます。

## 守るもの / 守らないもの

| | 方針 |
| --- | --- |
| サーバーを落とされる | **守る**。落ちると大会が止まる |
| 別のサイトに飛ばされる・埋め込まれる | **守る**。関係者が偽ページを掴まされると被害が外に出る |
| 画面に変なものを差し込まれる（XSS） | **守る**。上と同じ理由 |
| データを勝手に書き換えられる | **守る**。得点が壊れると大会が成立しない |
| なりすまし（他人の名前で入場する） | **守らない**。仲間内なので許容する |
| 大会の内容を第三者に見られる | **守らない**。もともと公開してよい情報しか置かない |

「なりすましを守らない」と決めているので、**ログインは合言葉ひとつ＋名前選びだけ**です。
そのぶん、上の 4 つは仕組みでしっかり止めます。

---

## 1. データを勝手に書き換えられないようにする

いちばん大事なところです。

```
読む   ブラウザ ──公開の鍵──> Supabase        ← 読むだけ
書く   ブラウザ ──> /api/** ──秘密の鍵──> Supabase  ← ここでしか書けない
```

ブラウザに配る鍵（anon）は **誰でも取り出せます**。URL を知っていれば見えます。
だから anon には「読む」しか許していません。

**新しいテーブルを作るときの決まり:**

```sql
alter table public.新しいテーブル enable row level security;
grant select on public.新しいテーブル to anon, authenticated;
grant all    on public.新しいテーブル to service_role;

create policy 新しいテーブル_public_read
  on public.新しいテーブル for select to anon, authenticated using (true);

-- insert / update / delete のポリシーは書かない ← これが書き込み禁止の実体
```

`for all` や `with check (true)` と書くと**誰でも書けるようになります**。書かないでください。

この約束は `tests/rls.test.ts` で毎回テストしています。テーブルを足したら、そこにテストも足してください。

## 2. サーバーを落とされないようにする

無料枠を使い切らせるのが、いちばん簡単な落とし方です。

- **一覧を読むクエリには必ず `.limit()` を付ける。**
  付け忘れると、1 回のアクセスで全件返して通信量の枠を食い潰します
- 検索ページは作らない（重いクエリの入り口になる）
- 大会当日にアクセスが荒れたら、Vercel の管理画面で
  **Attack Challenge Mode** を有効にする（人間かどうかの確認が入る）
- 画像を置かない。テキストだけなら通信量はまず枯れません

## 3. 別のサイトに飛ばされない・埋め込まれないようにする

`next.config.ts` のヘッダで止めています。設定済みなので、消さないでください。

- `frame-ancestors 'none'` / `X-Frame-Options: DENY` — 他サイトの中に埋め込ませない
- `base-uri 'self'` — リンクの行き先をまとめて書き換えられないようにする
- `form-action 'self'` — フォームの送信先を自サイトに限定する

**コードを書くときの決まり:**

- 画面の移動先に、URL などの外から来た値をそのまま使わない

  ```ts
  redirect(searchParams.next);        // ✗ 好きなサイトへ飛ばせてしまう
  redirect('/matches');               // ○ 行き先を自分で決める
  ```

- `<a href={外から来た値}>` を書かない（`javascript:` を入れられる）

## 4. 画面に変なものを差し込まれないようにする（XSS）

React は文字を自動でエスケープするので、普通に書いていれば安全です。
穴が空くのは 1 か所だけなので、そこを塞いでいます。

- `dangerouslySetInnerHTML` は **ESLint で禁止**（`react/no-danger`）。使えません
- HTML を差し込みたくなったら、まず設計を疑ってください

## 5. 秘密の値の扱い

- `NEXT_PUBLIC_` が付いた環境変数は**ブラウザに配られます**。秘密の値に付けないこと
- `SUPABASE_SERVICE_ROLE_KEY` は書き込み API の中だけ。`src/db/admin.ts` に
  `import 'server-only'` が入っていて、クライアントから使うとビルドが落ちます
- `.env.local` はコミットされません（`.gitignore` 済み）
- `.env.test` はコミットします。ローカル用の固定値しか入っていないためです

---

## 困ったときの連絡

不審なアクセスに気づいたら、まず Vercel の管理画面で該当のデプロイを止めてください。
データは Supabase に残るので、サイトを止めても消えません。
