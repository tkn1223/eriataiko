# 観戦者の入口を作り、チーム分けの無い大会でチーム選びを出さない

作った日: 2026-08-23

## なぜ作るか

**1. 観戦者の入口が無い。** 段1 のヒアリングで決めたのに、まだ作っていない唯一の項目。

**2. チーム分けをしない大会がある。** そのとき参加の記録（`entries`）にチームが入らないので、
**チームを選ぶ手順そのものが要らない。** いま押すものが無い画面が出るわけではないが、
「チームなし」というカードを 1 枚だけ押させるのは無駄な 1 手。

流れ自体は前の PR のまま。**チームが先で、その中を部で分ける。**

```
チームを選ぶ  →  名前をタップ  →  合言葉のシート  →  入場
```

## やること

### 1. 観戦者の入口

**最初の画面の一番下**に置く。押すと**合言葉を聞かずに**「見るだけ」の状態になる。

合言葉を設けたのは「まったくの他人にデータを見られたくない」ためだが、
運営として困るのは**書き込まれること**だけ。見るだけの人に合言葉を配ると
100 人に配る手間が戻ってくるので、見るだけなら素通しにする。

セッションに種類を持たせる。

| | 中身 | 合言葉 | 書き込み |
| --- | --- | --- | --- |
| `player` | 誰か（名前・番号・入力可） | **要る** | できる |
| `viewer` | 誰でもない | 要らない | **できない** |

`requireOperator()` が観戦者を **403** で弾く。観戦者は誰かを名乗っていないので、
書き込みの記録（`write_logs`）に残す名前がそもそも無い。**画面でボタンを隠すだけでは、
直接叩かれたら通ってしまう**ので、入口で止める。

**古い Cookie は締め出さない。** 種類が入っていない Cookie は、中身がそろっていれば
`player` として通す。観戦者を足す前に入場した端末を当日いきなり弾かないため。

### 2. チーム分けの無い大会

チームごとの束が **1 つしか無いときは、チームを選ぶ画面を出さない。**
チーム分けをしない大会では全員がチームなしになるので、ここが 1 つになる。

「前の大会のチームの行だけ残っていて、今回は誰も所属していない」も同じ扱いになる。
**束は人が居るチームだけで作る**ので、空のチームは数に入らない。

観戦者の入口は**このときも出す**（最初に開いた画面の一番下に置くため）。

### 3. 部の色を「並び順」で引く

名前の一覧では部が見出しになる。そこに色の点を付ける。

**部の名前ではなく、その大会での並び順**で色を引く。部の呼び名は大会ごとに変わる
（「1部」が「A級」になる）ので、名前で決めると次の大会で色が付かない。
**チームをまたいで同じ部が同じ色**になるよう、番号は大会の部の並びから取る。

色は 6 つに増やす（`--color-class-4` 〜 `-6` を追加）。
`ClassChip`（進行表で使う部のチップ）の名前決め打ちは**別の PR**で外す。

## やらないこと

- **画面の出し分け**（観戦者に得点ボタンを見せない）。セッションの形は用意したので、
  得点入力を作るときに使う
- `ClassChip` の作り替え
- 入場していない人を `/enter` に飛ばすこと
- `requireOperator()` に `can_input` の確認を足すこと

## 受け入れ基準

- [ ] 1 画面目に**チーム**が並び、人数が出る
- [ ] チームを選ぶと、そのチームの人だけが**部ごと**に並ぶ
- [ ] 部が未設定の人も、見出しなしで名前が出る
- [ ] 「← 戻る」でチーム選びに戻れる
- [ ] **チーム分けの無い大会では、チームを選ぶ画面が出ない**
- [ ] そのとき「← 戻る」も出ない（戻る先が無い）
- [ ] そのときも部の見出しは出る
- [ ] チームの行はあるのに誰も所属していない大会でも、チーム選びは出ない
- [ ] 観戦の入口が**最初の画面の一番下**にある
- [ ] チーム選びを出さないときも、観戦の入口が出る
- [ ] 名前を選ぶ画面まで進んだら、観戦の入口は出ない
- [ ] 観戦の入口を押すと、**合言葉を聞かれずに**「観戦中」になる
- [ ] 観戦中は「書き込めない」と画面に書いてある
- [ ] 観戦をやめられる
- [ ] **観戦者が書き込み API を叩くと 403**（`requireOperator`）
- [ ] 入場していない人は今までどおり 401
- [ ] 合言葉の欄が伏せ字でない／`one-time-code` でない（維持）
- [ ] 390px 幅で横にはみ出さない

## 決めたこと

| | 決定 | なぜ |
| --- | --- | --- |
| 1 画面目 | **チーム**（変更なし） | 当日はチームで固まって動く |
| チームが 1 束のとき | **チーム選びを出さない** | 押すものが 1 つしか無い画面は 1 手の無駄 |
| 観戦者の合言葉 | **聞かない** | 困るのは書き込みだけ。100 人に配る手間を戻さない |
| 観戦者の書き込み | **403 で弾く** | 誰かを名乗っていないので、記録に残す名前が無い |
| 古い Cookie | **人として通す** | 当日いきなり締め出さない |
| 部の色 | **並び順で引く。6 色** | 呼び名は大会ごとに変わる。数も増える |
| 観戦の入口の位置 | **最初の画面の一番下** | チーム選びを出さない場合も置き去りにしない |
