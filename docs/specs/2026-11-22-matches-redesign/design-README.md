# 引き継ぎ：進行表の作り直し＋過去の試合の訂正（えりあ太鼓 大会アプリ）

作った日: 2026-11-22 ／ 対象リポジトリ: `tkn1223/eriataiko`（`develop`）

## 概要

バドミントン大会の当日、約 100 人がスマホ（390px 基準）で使う。依頼者の不満 3 つに対するデザイン案。

1. 味気ない → 試合速報の得点板の言葉（チーム色の■・太い数字・金＝自分）を進行表へ持ち込む
2. 見たい試合まで遠い → 開いた直後に全コートの「いま・次」、コート札で飛ぶ、名前で探す、どこからでも試合の詳しい画面へ
3. 過去の試合を直せない → 試合の詳しい画面に［得点を訂正する］→ 直す画面（得点板の形）→ 完了

## このフォルダの HTML について

`*.dc.html` は **HTML で作ったデザインの見本**であり、そのまま使うコードではない。
既存の作り（Next.js / React・Konsta UI・Tailwind・`src/app/globals.css` の `@theme` 変数）で**作り直す**こと。
色は新しく作らず、下の「色」の表のとおり既存の変数に当てる。

- 開き方：`matches-redesign.dc.html` をブラウザで開く（`support.js`・`AppBar.dc.html`・`AppNav.dc.html` と同じフォルダに置く）
- 画面ごとの画像：`screens/*.png`（2 倍・各画面の下に「なぜそうしたか」のメモつき）

## 忠実度

**高忠実度（hi-fi）**。色・字の大きさ・余白・角丸・影は確定値。見本の数値どおりに作る。
ただし文言の一部（「決めてほしいこと」に関わるもの）は依頼者の判断で変わる。

## 前提（変えないこと）

- データの作り（表・書き込み口）は変えない。見せ方と動線だけ（例外は「決めてほしいこと」の 2e-B）
- ライトのみ・Web フォント無し（端末のゴシック）・大きな画像無し。印は線画 SVG
- 押せるところは 44px 以上（［−］［＋］・主ボタンは 46〜48px）
- 点数は `font-variant-numeric: tabular-nums`（既存の `.tabular` / `.score-number`）
- チームの色・部の色は既存（`class-labels.ts` と `globals.css`）から引く
