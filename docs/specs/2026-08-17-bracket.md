# 対戦表（/bracket）— 表示だけ

作った日: 2026-08-17

## なぜ作るか

大会中、選手も観戦者も「どのチームが勝っているか」「うちは何位か」を一番よく見る。
その場所がまだ無く、`/bracket` は「準備中！！」と出るだけ。

マイページ（`docs/specs/2026-08-16-me-page.md`）と同じで、チーム・試合を保存する表が
まだ無いので、先に見た目だけ作り、中身は見本の固定データで埋める。

## やること

`/bracket` に次を出す。見た目は運用中のアプリ（badminton-app）の対戦表に合わせる。

**上部**

- 見出し「対戦表」
- 丸い切り替え「予選リーグ」｜「決勝トーナメント」。押すと下の中身が入れ替わる

**予選リーグ側**

- 4×4 の星取表（枠線カードの中。狭い画面では表の中だけ横スクロール）
  - 行・列の見出しはチーム色の四角ドット＋チーム名
  - 自分同士のマスは空
  - 各マスは押せるボタン。上に印（勝ち `○` / 負け `●` / 進行中「試合中」/ 未実施「未」）、
    下にスコア（例 `1-0`。終了・進行中のみ）
  - 表の下に注記「○＝カード勝利（数字はカード内の勝ち試合数）。タップで詳細。」
- 「順位表（暫定）」— 順位 / チーム / 勝敗 / ゲーム / 得失点 の 5 列。
  自分のチームの行だけ薄い色で強調。下に「順位は 勝敗 → ゲーム → 得失点 の順で決定」

**決勝トーナメント側**

- 準決勝 → 決勝 → 優勝 の勝ち上がり表（中だけ横スクロール）と、3位決定戦
- まだ決まっていない枠は「予選 1位」「準決勝1 勝者」のように薄字
- 予選リーグ中は「組み合わせは予選リーグ終了後に確定します」と出す
- 優勝が決まっていれば「🏆 優勝：◯◯」の帯を出す

**マスを押したときの詳細**

- 画面の下から出るシート。見出しは「予選リーグ：A ◯-◯ B」、右上に「閉じる ✕」
- 中身はその対戦の試合一覧（部のラベル・両ペアの名前・スコア・進行中は LIVE）
- 背景の暗い部分・「閉じる」・`Esc` のどれでも閉じる

**あわせて**

- `/standings`（順位表のページ）を消す。順位表は対戦表の中に一本化する

## やらないこと

- DB からの読み取り（`src/db/` を触らない。見本の固定データを使う）
- 得点の入力・編集（見るだけ）
- 順位や勝敗の計算（順位は並んだ状態のデータとして持たせる）
- 予選リーグの結果から決勝トーナメントの組み合わせを自動で決めること
- 5 チーム以上への対応（今回は 4 チーム固定）

## 決めたこと

- **全部作る。** 切り替え・勝ち上がり表・3位決定戦まで含める。
- **マスの詳細（下から出るシート）も作る。** 中身は見本のダミー。
- **`/standings` は消す。** 同じ順位表が 2 か所にあると、後で片方だけ直して食い違う。
  参考アプリでも順位表は対戦表の中にある。
- **表示専用にする。** マイページ（`src/ui/me/`）と同じ形。部品は props を受け取って描くだけ。
- **横スクロールは表と勝ち上がり表の中だけに閉じ込める。** ページ全体は横に動かさない。
- **詳細シートは Tailwind で作る。** 参考アプリの見た目に合わせるため（Konsta の `Sheet` は使わない）。

## 残した宿題

- 本物のデータをつなぐ（チーム・試合の表がまだ無い）
- 順位と勝ち上がりの計算（`src/domain/`）
- 得点の入力（結果LIVE の画面）
- 4 チーム以外の大会
- 勝ち上がり表が横に続いていることの見せ方（390px では「決勝」の列が半分で切れる。
  横に動かせると気づかない人がいるかもしれない）
