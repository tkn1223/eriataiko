# 入場を「部 → 名前」に変え、観戦者の入口を作る

作った日: 2026-08-23

## なぜ作るか

前の PR で入場画面を「チーム → 名前」の 2 段階にしたが、**当日は部で分かれて動く。**
自分の部を先に選ぶほうが、探す手間が少ない。

あわせて、**観戦者の入口**を作る。段1 のヒアリングで決めたのに、まだ無い唯一の項目。

## やること

### 1. 1 画面目を「部」にする

```
部を選ぶ  →  名前をタップ  →  合言葉のシート  →  入場
```

チームは無くならない。**名前を選ぶ画面の中の見出し**になる（チーム色の点つき）。
部の中で誰が同じチームかが分かる。

部がまだ登録されていないときは、1 画面目を飛ばして名前の一覧を出す（前の PR と同じ考え）。

### 2. 部の色を「並び順」で引く

いまの `ClassChip` は部の名前（`'1部' | '2部' | '3部'`）で色を決めている。
**部の呼び名は大会ごとに変わる**ので、名前で決めると次の大会で色が付かない。

入場画面では**その大会の中での並び順**で引く。色は 6 つに増やす
（`--color-class-4` 〜 `-6` を追加）。`ClassChip` 側の作り替えは別の PR。

### 3. 観戦者の入口

**最初の画面の一番下**に置く。押すと**合言葉を聞かずに**「見るだけ」の状態になる。

合言葉を設けたのは「まったくの他人にデータを見られたくない」ためだが、
運営として困るのは**書き込まれること**だけ。見るだけの人に合言葉を配ると
100 人に配る手間が戻ってくるので、見るだけなら素通しにする。

セッションに種類を持たせる。

| | 中身 | 合言葉 | 書き込み |
| --- | --- | --- | --- |
| `player` | 誰か（名前・番号・入力可） | **要る** | できる |
| `viewer` | 誰でもない | 要らない | **できない** |

`requireOperator()` が観戦者を **403** で弾く。観戦者は誰かを名乗っていないので、
書き込みの記録（`write_logs`）に残す名前がそもそも無い。

**古い Cookie は締め出さない。** 種類が入っていない Cookie は、中身がそろっていれば
`player` として通す。観戦者を足す前に入場した端末を当日いきなり弾かないため。

## やらないこと

- **画面の出し分け**（観戦者に得点ボタンを見せない）。セッションの形は用意したので、
  得点入力を作るときに使う
- `ClassChip` の作り替え（部の名前の決め打ちを外す）
- 入場していない人を `/enter` に飛ばすこと
- `requireOperator()` に `can_input` の確認を足すこと

## 受け入れ基準

- [ ] 1 画面目に**部**が並ぶ（チームではない）
- [ ] 部のカードに人数が出る
- [ ] 部を選ぶと、その部の人だけが並ぶ
- [ ] 名前は**チームごと**にまとまり、チーム色の点と名前が出る
- [ ] 「← 戻る」で部選びに戻れる
- [ ] 部が 1 つも無いときは、いきなり名前が並ぶ
- [ ] 観戦の入口が**最初の画面の一番下**にある
- [ ] 部選びを飛ばしたときも、観戦の入口が出る
- [ ] 名前を選ぶ画面まで進んだら、観戦の入口は出ない
- [ ] 観戦の入口を押すと、**合言葉を聞かれずに**「観戦中」になる
- [ ] 観戦中は「書き込めない」と画面に書いてある
- [ ] 観戦をやめられる
- [ ] **観戦者が書き込み API を叩くと 403**（`requireOperator`）
- [ ] 入場していない人は今までどおり 401
- [ ] 合言葉の欄が伏せ字でない／`one-time-code` でない（維持）
- [ ] 390px 幅で横にはみ出さない

## 決めたこと

| | 決定 | なぜ |
| --- | --- | --- |
| 1 画面目 | **部** | 当日は部で分かれて動く。チームは名前の画面の見出しに回す |
| 観戦者の合言葉 | **聞かない** | 困るのは書き込みだけ。見るだけの人に配る手間を戻さない |
| 観戦者の書き込み | **403 で弾く** | 誰かを名乗っていないので、記録に残す名前が無い |
| 古い Cookie | **人として通す** | 当日いきなり締め出さない |
| 部の色 | **並び順で引く。6 色** | 呼び名は大会ごとに変わる。数も増える |
| 観戦の入口の位置 | **最初の画面の一番下** | 部選びを飛ばした場合も置き去りにしない |
